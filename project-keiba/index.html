🏇 競馬AI 予測システム v2

JRA 全レースを対象に、AIスコア1位の馬を全買いし続ける単勝 ROI のプラス化を目指して構築した予測システム。 データ取得から特徴量生成・モデル学習・毎日の新聞公開まで全自動で動いています。

→ 予測新聞を見る → モデルレポート

Background

目的

JRA の単勝控除率は約 20%。ランダムに馬を選び続けると期待 ROI は -20% になる。 このプロジェクトでは「AIがスコア1位と判断した馬を全レースで買い続ける」という シンプルな条件のもと、機械学習で -20% から回復させることを目標としています。

特定のレースを恣意的に選ぶ余地を残さず、システムが出す答えをそのまま受け入れるルールにすることで、 バックテストの過剰適合を避け、真の汎化性能を測っています。

Data Pipeline

データパイプライン

📡
JVLink API — 生データ取得
JRA 公式データ配信サービス（COM 経由）から 2013 年以降の全件を取得。
  • 成績データ（着順・タイム・上がり3F・コーナー通過順）
  • 血統データ（種牡馬・母父馬）
  • 騎手・調教師 成績履歴
⚙️
01_make_features.py — 特徴量エンジニアリング
生データから 491 列の特徴量を生成。リーク防止のため当該レースを shift(1) で除外。
  • 前走・近5走・近10走の成績集計
  • 騎手×コース・種牡馬×馬場 等のローリング統計
  • タイム指数・クラス調整着順・脚質分類
🗄️
all_venues_features.parquet
65 万行 × 491 列の学習用データセット（2013〜現在）。
🔮
06_predict_from_card.py — 当日予測
当日の出馬表を JVLink API で取得し、過去データと照合して特徴量を生成。5セグメント別モデルで単勝確率を推定。
📰
make_newspaper.py — 新聞生成・公開
スクレイピングでライブオッズ・馬体重を取得し、期待値フィルタで買い目を絞り込んだ HTML を自動生成 → GitHub Pages 公開。
  • netkeiba からライブオッズ・馬体重をスクレイピング
  • EV（期待値）フィルタで買い目を絞り込み

Model

モデル設計

アーキテクチャ

条件付きロジット（Conditional Logit）+ Isotonic Calibration。レース内での相対確率を直接モデル化。

最適化

Adam optimizer、Early stopping（validation NLL）、L2 正則化（λ = 0.006）。

特徴選択

ランダムサーチ（add / remove / swap）による greedy selection。最低 10 特徴を強制選択。

評価指標

2023-24 と 2025 の合算的中率（2325 スコア）で特徴を選択。単年 ±30% キャップ付き。

Segments

5セグメント構成

コースと距離でレースを5分割し、セグメントごとに独立したモデルを学習。 それぞれの特性に合った特徴量が自動選択されます。

セグメント 条件
ダート長距離ダート・1400m 超
ダート短距離ダート・1400m 以下
芝短距離芝・1400m 以下
芝中距離芝・1401〜2000m
芝長距離芝・2000m 超
